# Việt Nam Travel

Website tĩnh giới thiệu du lịch Việt Nam, được xây dựng bằng HTML5 và CSS3.

## Các trang
- `index.html`: Trang chủ
- `about.html`: Giới thiệu
- `destinations.html`: Địa điểm du lịch
- `contact.html`: Liên hệ

## Công nghệ
- HTML5
- CSS3
- Responsive Design
- Đường dẫn tương đối

## Chạy trên máy
Mở file `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload toàn bộ thư mục/file của dự án.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main`, thư mục `/ (root)`.
6. Nhấn **Save** và chờ GitHub Pages xuất bản.

## Nguồn hình ảnh
Hình ảnh trong thư mục `images/` được tạo minh họa cho bài tập, không sử dụng ảnh tải trực tiếp từ website bên ngoài.
